# GOOBER OS

GOOBER (General Operations & Onboard Base Environment Response) is a CC:Tweaked facility interface. The repository is being built in phases; this first foundation release installs a local boot screen and stores device configuration.

## Current status

- Step 1: installer, startup entry point, persistent device configuration, and capability detection.
- Step 2 and later: distributed networking, full UI, shared music, announcements, lockdown, history, and updater are not implemented yet.

Read [docs/step-1.md](docs/step-1.md) for GitHub publishing and in-game installation details. The installer asks for the raw-content repository root; no owner or repository is hardcoded.
